# Frontend Design Skill

## Rule

Follow the `frontend-design` skill when building new UI or reshaping existing UI in this project.

## Details

- Skill location: `.agents/skills/frontend-design/` (registered via `skills.paths` in `opencode.json`).
- Use it for aesthetic direction, typography, and distinctive visual choices — avoid templated defaults.
- Ground design decisions in the product's subject and audience.
