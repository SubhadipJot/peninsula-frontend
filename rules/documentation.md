# Documentation

## Rule

Record every major change to this project in the `docs/` folder.

## Details

- Create one dated file per change: `docs/changes/YYYY-MM-DD-short-description.md`.
- Update the table in `docs/index.md` to include the new entry.
- Major change means anything that meaningfully alters the project: new features, refactors, dependency/stack changes, config changes, etc.
- Keep entries concise: summary, what changed, relevant commands, verification steps.
